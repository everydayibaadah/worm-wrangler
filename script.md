# Worm Wrangler Project Overview

## Introduction

Welcome to the Worm Wrangler project overview. This video will walk you through the codebase and demonstrate the gameplay. Worm Wrangler is a fun, interactive web-based game where players test their reflexes by catching worms that pop up from holes.

## Codebase Overview

The project is structured into three main parts: HTML for the structure, CSS for styling, and JavaScript for the game's functionality.

### HTML Files

- **`index.html`**: This is the entry point of our application. It displays the introduction page, where players can choose their gloves and adjust sound settings before starting the game.
- **`gamePage.html`**: This file contains the main game interface. It includes the game board with holes for the worms, the scoreboard, and various buttons for game control.

### CSS Files

- **`css/introPage.css`**: This stylesheet is responsible for the look and feel of the introduction page. It styles the glove selection area, buttons, and other UI elements to create an engaging initial experience.
- **`css/gamePageCss.css`**: This file styles the main game page. It includes styles for the game board, worms, scoreboard, and custom cursor, creating an immersive and visually appealing game environment.

### JavaScript Files

- **`javascript/introPage.js`**: This script handles the logic for the introduction page. It manages glove selection, sound controls, and transitions to the game page, ensuring player preferences are saved and applied.
- **`javascript/gamePageScript.js`**: This is the core of our game. It manages all the game logic, including starting the game, making worms appear and disappear, tracking the score and misses, and handling the game-over conditions.
